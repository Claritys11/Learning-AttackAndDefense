# Event and process monitoring

## Objective
Detect the actions used in an attack without destroying service availability.

## Practice
Correlate timestamp, actor, process, command/file/network event, result, and request ID. Use structured redacted evidence.

## Lab mapping
Enumeration and Mini A&D contracts; a dedicated monitoring fixture is planned.

## Mastery
Explain what signal would detect the exploit, how to reduce noise, and how to test the detector locally.
