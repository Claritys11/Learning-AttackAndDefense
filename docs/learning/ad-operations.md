# A&D operations

## Objective
Run attack and defense lanes under time, scope, health, evidence, and rollback constraints.

## Order
`baseline own -> map enemy fixture -> attack -> patch own -> health/SLA -> replay -> evidence -> review`.

## Lab mapping
[Mini A&D](../../labs/05-mini-ad/README.md) and [competition runbook](../competition-runbook.md).

## Rule
Automation is late-stage. Manual understanding and local fixtures are acceptance criteria before multi-solver or platform adapters.
