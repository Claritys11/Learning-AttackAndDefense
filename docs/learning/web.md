# Web attack and defense

## Objective
Analyze HTTP behavior, discover routes, reproduce a local vulnerability, patch its cause, and verify regression.

## Practice
Use `curl` for manual requests, browser devtools/Burp in local labs, and record status, headers, body, method, and parameters.

## Lab mapping
[Enumeration](../../labs/01-enumeration/README.md), [Command Injection](../../labs/02-command-injection/README.md), [Path Traversal](../../labs/03-path-traversal/README.md), [Auth Bypass](../../labs/04-auth-bypass/README.md).

## Mastery
Complete whitebox, graybox, blackbox, defense, and timed modes without contacting public targets.
