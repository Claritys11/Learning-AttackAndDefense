# Authentication and authorization

## Objective
Separate identity proof, session/token validation, and authorization decisions.

## Practice
Build an actor × endpoint matrix. Review expiry, issuer, audience, signature, algorithm, session binding, and server-side role checks.

## Lab mapping
[Auth Bypass](../../labs/04-auth-bypass/README.md).

## Mastery
Reproduce an unauthorized local action, patch the trust boundary, and prove anonymous/user/admin behavior remains correct.
