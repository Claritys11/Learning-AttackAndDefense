# Networking and access

## Objective
Understand TCP/UDP, ports, DNS, HTTP, SSH, VPN boundaries, and egress.

## Mental model
An A&D round is a time-varying set of services, routes, identities, and trust boundaries.

## Practice
Use `ip`, `ss`, `dig`, `curl`, and `tcpdump` against localhost or explicitly authorized labs.

## Lab mapping
[Enumeration](../../labs/01-enumeration/README.md), [Mini A&D](../../labs/05-mini-ad/README.md).

## Mastery
Produce an asset map, explain each connection, and write a scoped firewall rule without breaking health.
