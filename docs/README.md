# GZCTF A&D Research Map

This directory contains source captures from the requested documentation pages. They are retained as research artifacts, not as a substitute for the upstream/fork source code.

- `source-access.txt` — WireGuard and SSH team access plane
- `source-snapshots.txt` — end-of-game image and per-round change manifests
- `source-honeypots.txt` — HTTP/protocol decoys and suspicion signals
- `source-anti-cheat.txt` — evidence, suspicion scoring, traffic, and reports
- `source-challenge-yaml.txt` — importer schema and silent unknown-key behavior

The long-form synthesis is `gzctf-ad-workflow-analysis.md`.
